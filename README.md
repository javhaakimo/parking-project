# Parking Management System

A simple Python console project for managing vehicle entry and exit records.

## Features

- Add vehicle entry
- Record entry time
- Remove vehicle when exiting
- View currently parked vehicles
- Store data in a text file

## Technologies

- Python
- File Handling
- Functions
- Lists
- Dictionaries

## Project Purpose

This project was created as part of my Python learning journey while studying to become an AI Engineer.
